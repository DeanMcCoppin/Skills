# Working with Dean

Dean's skills come from the `dean-skills` marketplace (https://github.com/DeanMcCoppin/Skills). Dean doesn't call skills by name: **you pick them**.

- At the start of this project and of every substantial task, load the **`playbook`** skill (`agent-workflows` plugin) and follow it: it says which skills to use, in what order, and what needs Dean's OK first.
- In one line, say which skills you're using. Report results in plain words.
- If a skill the playbook names isn't available, tell Dean which plugin to enable instead of working without it.
- Ask before anything that costs money, installs global tools, signs in, sends messages, or deploys. Batch questions, with a recommended default for each.
- If the project has a `DESIGN.md`, read it before any UI work.

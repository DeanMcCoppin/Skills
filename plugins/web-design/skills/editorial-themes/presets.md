# Mood presets

Starting points. Mix and adjust per brief. The accent column is optional; "none" is often the stronger choice.

| Preset | Fits | Mode | Type | Accent | Signature moves |
| --- | --- | --- | --- | --- | --- |
| **Counsel** | law, accounting, finance, consulting | light | Newsreader (serif) headlines + Inter body | deep teal `oklch(0.34 0.036 207)` | dim full-bleed photo hero with nav over it; serif headline left, paragraph right; stat row of results; people grid with roles |
| **Studio dark** | agency, design studio, production | dark | one grotesk (General Sans), huge display with very tight tracking | none | giant headline over an indexed work grid (`01 … 2025`); metadata rows; scroll-brightening statement paragraph; marquee of service words with inline thumbnails |
| **Gallery** | architecture, interiors, photography | light or dark | one grotesk (Switzer), modest sizes | none | split screen: small text and contact on the left, sticky full-bleed photo on the right; "MENU" nav; thumbnail strips; project index as a table |
| **Nordic listing** | real estate, cabins, manufacturers | light | grotesk, medium display | none or muted green | photo grid with a fact row per item (area, rooms, price); neighborhood/guide sections; agent cards |
| **Quiet luxury** | car rental, hotels, watches, fashion | light | grotesk, small caps labels | none | product on white, huge negative space; detail-shot grids; numbered specs; booking CTA in the nav |
| **Craft editorial** | barbershop, restaurant, bakery, salon | warm off-white | grotesk wordmark + centered short statement | none or one warm tone | portrait-led hero; very short centered manifesto line; services and prices as a clean list; "Looks" or menu grid |
| **Swiss school** | university, school, institutions, events | light with black blocks | heavy-feeling grotesk at 500, all-caps section titles | one bright block color | strong grid, B&W photography with one color-graded panel; big quote blocks; programme tables |
| **Structured SaaS** | SaaS, fintech, APIs, dev tools | light or dark | grotesk, optional serif headline | one accent | product screenshots in plain frames; feature grid with hairline dividers; pricing table; changelog/docs pages; code blocks in mono |
| **Newsprint** | magazine, news, blog, podcast | off-white | serif headlines + grotesk meta | red or none | multi-column front page; bylines and dates as small meta; bento of square cards; issue/episode archive |

## Industry page add-ons

- **Law / accounting**: Practice areas, Attorneys/Team (+ profile), Results/Case studies, Offices, Consultation form.
- **Agency / studio**: Work index + case study (challenge, approach, outcome, credits), Services, Studio/Team, Journal.
- **Architecture / interiors / photography**: Projects index (table + grid toggle), Project detail (gallery, facts), Archive, Rates, Contact.
- **Real estate**: Listings (filters, fact row), Listing detail (gallery, facts, map, agent), Neighborhoods, Agents.
- **Restaurant / hospitality**: Menu, Reservations, Private dining/Events, Location and hours, Gallery.
- **Clinic / dental / physio**: Treatments, Team, Pricing, Booking, FAQ, Patient info.
- **SaaS**: Features, Pricing, Customers, Changelog, Docs, Blog, Sign-in/Sign-up.
- **Magazine / blog / podcast**: Front page, Category, Article, Episode, Author, Newsletter.
- **Jobs / directory**: Listings with filters, Listing detail, Submit form, Company profile.

## Free fonts that fit

- Grotesks: Switzer, General Sans, Satoshi (Fontshare); Inter, Geist (Google / Vercel)
- Serifs: Newsreader, Instrument Serif, Fraunces, Source Serif 4 (Google)
- Mono: Geist Mono, JetBrains Mono

Check each font's license before shipping (Fontshare fonts use the ITF Free Font License).

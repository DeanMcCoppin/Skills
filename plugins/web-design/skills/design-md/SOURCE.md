## Notes

- Verdict: the DESIGN.md habit is worth adopting in every project (one file keeps every agent and session on-brand). The collection is a good reference for how to write one, not a source of looks to reuse for clients.
- Good at: real token values plus prose rules, a format other tools (Stitch, other agents) read too.
- Weak at: third-party analyses can be wrong or outdated; moving content to getdesign.md (marketing funnel); temptation to clone brands.
- Alternatives: `design-system` (extract tokens from existing code), `refero` (real product screens), `penpot` design tokens.

## Notes

- Verdict: baseline for every frontend task; other web-design skills build on it.
- Good at: stack defaults (Next.js, TypeScript, Tailwind, Framer Motion), anti-generic-AI rules, purposeful motion, polished maps.
- Weak at / risks: fonts, colors and component libraries are still TODO, so until they're filled in, results vary from project to project.
- Alternatives: `editorial-themes` for full theme sites (it overrides this where they differ). Detailed passes: `motion`, `interface-polish`, `design-system`, and `accessibility` (code-audit).

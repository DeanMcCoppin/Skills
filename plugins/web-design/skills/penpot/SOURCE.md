## Notes

- Verdict: a real free Figma alternative for Dean's own design work, made more interesting by the official MCP. Stay in Figma when a client lives there.
- Good at:
  - free, unlimited editors
  - CSS-native layouts and design tokens
  - self-hostable
  - official MCP for design-to-code and code-to-design
- Weak at / risks:
  - smaller plugin ecosystem than Figma
  - performance on huge files
  - the MCP runs arbitrary code in the plugin environment (scope it to the files you intend)
  - MCP setup is local and manual
  - pricing not verified here
- Alternatives: Figma (industry standard, paid); Framer (design + publish); Lunacy (free)
